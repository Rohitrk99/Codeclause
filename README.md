# Socket.IO Real-time Chat Project
Developed a real-time chat application using WebSockets where users can join with a username, view ongoing conversation history, receive live message updates and notifications when users join or exit, with clear message labeling for sender and others.

## Tech Stack
- HTML

- CSS

- Socket.IO

## Features
- Username-based chatroom entry (no full authentication)

- Real-time messaging with instant transmission and reception

- Message history visible to newly joined users

- Join and exit notifications broadcasted to all users

- Clear sender identification through message labels (e.g., "You", usernames)

- Real-time communication using WebSockets with event-driven updates
> The app instantly sends and receives messages using a live WebSocket connection. Events like "user joined", "message sent", or "user left" trigger immediate updates for all users.
## For testing
- To simulate multiple users in the chatroom, please open the app in different browser tabs or use incognito/private windows. This allows you to experience real-time updates and user-specific messaging as intended.
